# neattab

Edge / Chromium（MV3）书签新标签页扩展。无框架、无构建、不联网。

## 安装

1. 打开 `edge://extensions`（Chrome：`chrome://extensions`），开启「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择包含 `manifest.json` 的目录。
3. 更新权限或版本后，在扩展管理页点击**重新加载**。

## 快捷键

| 按键 | 行为 |
|---|---|
| `/` | 聚焦全局搜索 |
| `↑` `↓` `←` `→` | 网格移动选择 |
| `Enter` | 打开书签 / 进入分组 |
| `Ctrl` + `Enter` | 新标签页打开 |
| `Esc` | 清空搜索 / 返回上级 / 关闭弹窗 |
