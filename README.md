# NeatTab — 书签导航

面向 Edge / Chrome 等 Chromium 浏览器（Manifest V3）的本地书签新标签页扩展。离线运行，不读取浏览历史。

## 特点

- 直接读取浏览器自带的收藏夹，不另建数据库，也不需要账号；改完书签两边同步生效。
- 点击工具栏收藏当前页时，会参考你已有的书签在本地猜分组；遇到文章或帖子页，会优先推荐放进「阅读清单」，顺手清理网址末尾的评论锚点。
- 文件夹命名包含「阅读 / 稍后 / 待看 / 文章 / 帖子」时，会自动按网站归类、按收藏时间倒序排列，适合存临时要看的内容。
- 可以直接搜索并选用电脑里已安装的系统字体，支持浅色 / 深色切换。

## 安装

无需编译，直接以解压缩扩展加载：

1. 打开 `edge://extensions`（Chrome 打开 `chrome://extensions`）。
2. 开启 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择本项目根目录（包含 `manifest.json`）。

更新代码后，在扩展管理页点击 **重新加载** 即可生效。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `↑` `↓` `←` `→` | 在网格中移动选中项 |
| `Enter` | 打开选中书签 / 进入选中分组 |
| `Ctrl` + `Enter` | 在新标签页打开选中书签 |
| `Esc` | 清空搜索 / 返回上级分组 / 关闭弹窗 |

按住 `Ctrl`（macOS 为 `⌘`）或中键点击书签，始终在新标签页打开。

## 权限说明

- `bookmarks`：读取收藏夹用于展示；仅在用户主动编辑、拖拽或保存时写入。
- `storage`：本地保存主题、字体、收藏星标、浏览位置与分类样本。
- `favicon`：读取浏览器本地缓存的站点图标。
- `activeTab`：仅在点击工具栏图标时读取当前标签页标题与网址。
- `fontSettings`：读取本机已安装字体列表。
