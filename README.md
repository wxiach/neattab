# NeatTab — 书签导航

一个把浏览器收藏夹变成高效新标签页的扩展，基于 Vite + React + TypeScript + Tailwind v4 + Base UI（coss ui 风格）构建。

> 点击工具栏收藏网页时支持本地模型秒出推荐，并可按需开启 DeepSeek 结合当前网页摘要自动优化命名与分类（含建议新建分类），以及在系统设置中使用 AI 智能整理（批量重命名、归类与目录体检）。

## 安装与构建

1. 克隆仓库并安装依赖：

   ```bash
   git clone https://github.com/wxiach/neattab.git
   cd neattab
   pnpm install
   pnpm run build
   ```

2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择构建产物目录 **`dist/`**。

拉取更新后，重新执行 `pnpm run build`，并在扩展管理页点击 **重新加载** 即可。

## DeepSeek AI 助手（可选）

- 默认关闭，不开启时完全在本地运行；默认模型为 `deepseek-flash`（`DeepSeek-V4.1-Flash-1017`），并默认关闭思考模式以降低延迟。
- 在「系统设置 → AI 助手」中填写 DeepSeek API Key 并开启开关后：
  - **单页智能收藏**：打开工具栏弹窗时先 0ms 展示本地分类结果，后台提取当前页摘要（`meta description`、`h1` 与正文前段）并请求 DeepSeek 优化标题与分类（若你已手动编辑则不覆盖）；当现有分类均不合适时会以虚线标签建议新建分类，仅在确认保存时创建。
  - **AI 智能整理（重命名 / 归类 / 目录体检）**：在「系统设置 → AI 助手」中打开，包含两个页签：
    - **书签整理**：按分组、我的收藏或全部书签分批生成标题精简与（可选）改分目录建议，支持逐条勾选或编辑，确认后写回。
    - **目录体检**：全局审视目录结构，提出合并重复分类、清理空目录、规范目录名与拆分臃肿目录的建议；应用前自动下载完整 JSON 备份，且仅在迁出全部书签并二次校验为空后才移除旧空目录。
