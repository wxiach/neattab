# NeatTab — 书签导航

一个把浏览器收藏夹变成新标签页的扩展，直接读取本地收藏夹，不需要账号。收藏网页时会根据已有书签在本地推荐分组，阅读清单类文件夹会自动按网站和收藏时间归类整理。

## 安装

1. 克隆本仓库：

   ```bash
   git clone https://github.com/wxiach/neattab.git
   ```

2. 在浏览器打开 `edge://extensions`（Chrome 打开 `chrome://extensions`），开启 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择包含 `manifest.json` 的目录。

后续拉取最新代码后，在扩展管理页点击 **重新加载** 即可更新。
