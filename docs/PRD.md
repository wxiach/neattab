# neattab · 产品规格（PRD）

## 1. 范围

- **目标**：新标签页书签索引与工具栏本地分类收藏。
- **非目标**：批量操作、撤销、三级及以上目录、云同步、历史记录读取、网络请求。

## 2. 信息架构

| 区域 | 组成 | 规则 |
|---|---|---|
| 顶栏 | 品牌标识、全局搜索、主题切换 | 搜索框不自动抢占地址栏焦点 |
| 侧栏 | 我的收藏、一级/二级分组树、偏好设置入口 | 最多两级；更深层拍平至二级；散装书签归入「我的收藏」 |
| 主区 | 面包屑、新建分组按钮、内容网格 | 上级面包屑可点击返回；全站统一网格 |
| 工具栏弹窗 | 当前页摘要、名称、分组、新建分组、收藏/去锚点勾选 | `368px` 宽；仅支持 `http/https` 页面 |

## 3. 功能需求

| 编号 | 模块 | 规格 |
|---|---|---|
| F1 | 数据源 | 默认读取收藏夹栏（`rootId="1"`），可切换至任意一级目录；书签变更 150ms 防抖刷新。 |
| F2 | 视图记忆 | 持久化上次选中分组与展开状态；目标不存在时回退至首个含子分组的目录。 |
| F3 | 内容网格 | 零空隙 1px 细线网格；书签含图标/标题/域名，文件夹含图标/名称/条目数/箭头；父目录先书签后文件夹。 |
| F4 | 阅读清单 | 匹配「阅读/稍后/待看/文章/帖子」的单层目录：展示时按站点域名分段（最近收藏站点在前），站内按 `dateAdded` 倒序，副标题显示收藏时间。 |
| F5 | 全局搜索 | 跨全部分组匹配标题与网址（不区分大小写），`<mark>` 高亮命中词，支持一键清空。 |
| F6 | 显式编辑 | 右键菜单提供收藏、重命名、新建子分组、移动到、删除（二次确认并统计连带项）；支持书签拖拽排序与跨组移动。 |
| F7 | 主题与字体 | 主题支持跟随系统/浅色/深色（无闪烁切换）；字体读取本机全部系统字体，向下悬浮可搜索列表实时预览。 |
| F8 | 设置入口 | 主页居中弹窗即时生效；保留独立 `options.html` 供扩展管理页使用。 |
| F9 | 工具栏收藏 | 区分站点入口与内容页（帖子/文章/视频/Issue）；内容页优先推荐「阅读清单」并可选移除 `#reply` 锚点；本地模型预选分组并支持窗内新建分组，确认后写入。 |

## 4. 视觉基线

| 项 | 浅色 | 深色 |
|---|---|---|
| 画布 / 纸张 | `#F4F4F5` / `#FFFFFF` | `#0E0E11` / `#17171B` |
| 图标底托（`32×32`） | `#FFFFFF` | `#26262E` |
| 强调色 / 星标色 | `#2563EB` / `#D97706` | `#60A5FA` / `#FBBF24` |

- **形态**：全局 `0px` 直角（仅二级选中指示点为圆形）；图标失败用首字母方块兜底。
- **可读性**：字号 `≥ 11px`；过渡 `≤ 150ms`；全部交互控件提供 `:focus-visible`。
- **响应式**：`≤ 960px` 侧栏转横向条；`≤ 720px` 网格转单列，无横向滚动。
