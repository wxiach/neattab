# neattab Changelog

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与 [SemVer 2.0.0](https://semver.org/lang/zh-CN/)。

## [0.1.0] - 2026-11-25

### Added
- 新标签页书签索引：左侧两级分组树（「我的收藏」+ 折叠与视图记忆）、右侧零空隙 1px 直角细线网格。
- 全局即时搜索（`<mark>` 高亮、一键清空）与全键盘导航（`/`、`↑↓←→`、`Enter`、`Ctrl+Enter`、`Esc`）。
- 显式书签编辑：右键菜单（收藏、重命名、新建分组、移动、二次确认删除）及拖拽整理。
- 阅读清单视图：单层目录按站点域名分段、站内按收藏时间倒序，副标题展示收藏时间。
- 居中直角设置弹窗与独立兜底页：无闪烁深浅主题切换、基于 `fontSettings` 的向下悬浮可搜索系统字体选择器。
- 工具栏快捷分类收藏弹窗：站点入口/内容页自动识别、回复锚点清理、本地在线学习分类模型与窗内新建分组。
