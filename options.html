设置

改动即时生效，无需手动保存。

外观与常规

外观

中性灰画布 + 直角独立白卡片；深色模式采用温润深炭灰配色。

字体

直接读取本机已安装字体，支持搜索，选中后即时预览。

打开方式

按住 Ctrl / ⌘ 点击，或中键点击，始终在新标签打开。

数据与备份

数据来源

新标签页只展示这个目录里的书签。默认读取 Edge 的「收藏夹栏」。

导入导出

导出精简 JSON 便于备份或交给 AI 整理；导入支持选文件或直接粘贴，严格保持顺序。

快捷键

快捷操作
/
聚焦全局搜索
↑↓←→
在网格中移动选择
Enter
打开书签 / 进入分组
Ctrl+Enter

右键 / F2

关于与权限

权限与隐私

只申请 bookmarks、storage、favicon、activeTab 与 fontSettings：读写收藏夹（仅显式编辑/收藏写入）、存本地偏好与分类样本、取本地站点图标、点击扩展图标读取当前页信息以及列出本机系统字体。不读历史、不联网。

书签变化时，已打开的新标签页会自动刷新。
